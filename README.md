# 당류 NIR 판별 파장 영역 선택 (400–2500 nm → PLS)

포도당으로만 된 α-1,4 사슬인 포도당(DP1), 말토오스(DP2), 말토트리오스(DP3), 말토테트라오스(DP4)를 PLS로 정량하기 전에,
400–2500 nm에서 **당끼리 구분되는 영역만** 골라 모델에 넣는 파이프라인입니다.

## 아이디어

| 단계 | 내용 | 비용 |
|---|---|---|
| 1. 물리 모델 | O-H / C-H 진동자마다 1D Morse 퍼텐셜 슈뢰딩거 방정식을 유한차분으로 풀어 오버톤 위치·세기를 계산하고, 결합대(신축+굽힘, 신축+C-O)를 더함. 당은 작용기 개수로 표현: 1차/2차/아노머 OH, 고리 CH, 환원 말단 C1-H, 글리코시드 C1-H, 결합된 C4-H, CH2. DP가 n이면 환원 말단 1개, 글리코시드 결합 n-1개 | 진동자당 ms 수준 (DFT 불필요) |
| 2. 이론 선택성 | 각 당의 순 분석 신호(NAS): 다른 당, 물(온도 변화 포함), 색소, 베이스라인과 직교하는 성분을 노이즈로 나눠 파장별 선택성 계산 → 상위 영역 | 측정 데이터 불필요 |
| 3. 데이터 보정 | 이론 영역을 후보로 두고 backward iPLS로 불필요 구간 제거 (hybrid) | 검량 세트 CV |
| 4. 검증 | 독립 테스트 세트 RMSEP로 전체 파장 PLS와 비교 | |

이론 선택성 계산에는 밴드 위치 ±15 cm⁻¹, 폭 ±15 %, 세기 ±20 %의 **모델 오차를 일부러 넣었습니다**.
실제 시료와 이론이 어긋나도 영역 선택이 버티는지 보기 위해서입니다.

## 실행

```bash
pip install -r requirements.txt
python run_experiment.py --repeats 5
```

결과: `results/report.md`, `results/*.png`, `results/results.json`

## 주요 결과 (시뮬레이션, 5회 반복)

- **스펙트럼 정보는 사실상 2차원입니다.** 그램당 순수 스펙트럼(DP1~DP4)의 특이값은 1 : 0.087 : 0.0018 : 0.0001입니다.
  α-1,4 포도당 사슬은 DP가 늘어도 반복 단위가 같고, 달라지는 건 환원 말단 비율(1/DP)과 글리코시드 결합 비율뿐이기 때문입니다.
- 그래서 **각 당을 따로 정량하는 건 어렵고**(DP2~DP4 개별 R² 0.2~0.45, 포도당 0.88),
  **총 당량(R² 0.999), 환원 말단 농도(R² 0.991~0.996), 평균 중합도 DP(R² 0.83~0.84)** 는 잘 예측됩니다.
- **핵심 영역**: 약 1520–1590 (OH 1차 오버톤, 아노머 OH), 1710–1800 (CH 1차 오버톤: 아노머·글리코시드·C4-H),
  2050–2220 (OH 결합대), 2250–2375 nm (CH 결합대, OH+C-O). 공통 합집합은 전체 파장의 약 24 %입니다.
- **400–1000 nm(가시광)는 쓸모가 없습니다.** 4~5차 오버톤은 세기가 10⁻³ 이하이고, 색소·산란 노이즈만 들어옵니다.
- 평균 DP는 영역을 고르면 R²가 0.75(전체 NIR)에서 0.83~0.84로 오릅니다. 반면 VIP 단독은 가시광 색소 영역을 잘못 골라 성능이 나빠집니다.

## 한계

- 밴드 파라미터(ωe, ωexe, 결합 파트너 주파수)는 문헌 기반 근사값입니다. 실측 순수 성분 스펙트럼으로 보정하면 이론 영역의 정확도가 올라갑니다.
- 고체/분말 시료는 수용액보다 OH 밴드가 날카롭고 위치가 달라서, 삼·사당류 분리 가능성이 더 높을 수 있습니다.
- 최종 영역은 **반드시 실측 데이터의 독립 검증 세트**로 확인해야 합니다. 같은 데이터로 영역 선택과 평가를 모두 하면 성능이 과대평가됩니다.

# 과당 / 알룰로스 영역 선택 (4000–16000 cm⁻¹, 호변이성질체 모델)

```bash
python run_ketose.py --repeats 5
```

결과: `results_ketose/report.md`, `results_ketose/*.png`

## 모델

- 두 당 모두 C6H12O6 케토헥소스(알룰로스 = 과당의 C3 에피머)라서 작용기 개수가 같습니다.
  차이는 **호변이성질체 분포**와 **OH 방향 / 분자 내 수소결합**에서 나옵니다.
- 이성질체마다(β/α-피라노스, β/α-퓨라노스, 케토) 따로 X-H 진동자를 정의합니다: 헤미케탈 OH, 축/적도 OH, 1차 OH, 축/적도 CH, 퓨라노스 CH, 고리 O-CH2, CH2OH.
  알룰로스는 피라노스에서 C3-OH가 축 방향이고 퓨라노스에서 3,4-cis 디올이라, 분자 내 수소결합 OH(`OH_hb`)로 넣었습니다.
- 당의 스펙트럼은 이성질체 비율로 가중합합니다. 비율은 온도에 따라 변합니다(가열하면 퓨라노스 증가).

| 25 °C 비율 | β-피라노스 | α-피라노스 | β-퓨라노스 | α-퓨라노스 | 케토 |
|---|---|---|---|---|---|
| 과당 | 68 % | 3 % | 22 % | 6 % | 0.5 % |
| 알룰로스 | 24 % | 22 % | 15 % | 39 % | 0.3 % |

- 이론 선택성(NAS)을 계산할 때는 상대 당, 물(온도 변화 포함), **각 당의 온도에 따른 이성질체 비율 변화**, 색소, 베이스라인을 간섭 성분으로 제거합니다.
  비교용으로 "우세 이성질체 하나만" 쓴 단순 모델도 함께 돌립니다.

## 추천 영역 (cm⁻¹)

| 영역 | nm | 무엇을 보는 곳 |
|---|---|---|
| 4110–4310 | 2320–2430 | CH 결합대 (축 CH, 고리 O-CH2, CH2OH) |
| 4350–4950 | 2020–2300 | OH 결합대 (헤미케탈 OH, 수소결합 OH + C-O) — 두 당 차이가 가장 큼 |
| 5500–5840 | 1710–1820 | CH 1차 오버톤 (피라노스 vs 퓨라노스 CH) |
| 6110–6620 | 1510–1640 | OH 1차 오버톤 (적도 OH vs 분자 내 수소결합 OH) |
| 9450–9620 | 1040–1060 | OH 2차 오버톤 (약하지만 물 간섭이 적음) |

전체 포인트의 약 16 %만 사용합니다. 10000 cm⁻¹ 이상(1000 nm 이하)은 4차 이상 오버톤이라 거의 쓸모가 없습니다.

## 결과 (시뮬레이션, 5회 반복)

- 과당·알룰로스·총 당은 어떤 방법이든 R² ≥ 0.998입니다. 영역을 고르면 RMSEP가 약 10–15 % 줄어듭니다.
- **알룰로스 비율(전환율)은 PLS로 직접 예측하지 말고**, 두 농도 모델의 예측값으로 계산하세요. 직접 예측하면 R² 0.82, 계산하면 R² 0.996입니다.
- **온도 견고성(검량 25 °C → 측정 35 °C)에서 호변이성질체 모델의 효과가 납니다.**
  알룰로스 비율 RMSEP: 전체 파수 7.3 % → 우세 이성질체만 쓴 이론 영역 4.4 % → **호변이성질체 이론 영역 3.2 %**.
  다만 과당 단독 농도는 데이터 기반 iPLS가 더 견고했습니다(0.48 vs 0.70 g/100 mL). 그래서 최종 영역은 이론으로 후보를 잡고 실측 데이터로 확인하는 순서를 권합니다.
- 실제 운전 온도가 바뀐다면 검량 세트에 여러 온도를 넣거나 온도를 일정하게 유지하는 게 영역 선택보다 효과가 큽니다.
