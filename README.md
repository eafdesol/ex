# 당류 NIR 판별 파장 영역 선택 (400–2500 nm → PLS)

단당류(포도당), 이당류(수크로스), 삼당류(라피노스), 사당류(스타키오스)를 PLS로 정량하기 전에,
400–2500 nm에서 **당끼리 구분되는 영역만** 골라 모델에 넣는 파이프라인입니다.

## 아이디어

| 단계 | 내용 | 비용 |
|---|---|---|
| 1. 물리 모델 | O-H / C-H 진동자마다 1D Morse 퍼텐셜 슈뢰딩거 방정식을 유한차분으로 풀어 오버톤 위치·세기를 계산하고, 결합대(신축+굽힘, 신축+C-O)를 더함. 당은 작용기 개수(1차/2차/축방향/아노머 OH, 고리/퓨라노스/글리코시드 CH, CH2)로 표현 | 진동자당 ms 수준 (DFT 불필요) |
| 2. 이론 선택성 | 각 당의 순 분석 신호(NAS): 다른 당, 물(온도 변화 포함), 색소, 베이스라인과 직교하는 성분을 노이즈로 나눠 파장별 선택성 계산 → 상위 영역 | 측정 데이터 불필요 |
| 3. 데이터 보정 | 이론 영역을 후보로 두고 backward iPLS로 불필요 구간 제거 (hybrid) | 검량 세트 CV |
| 4. 검증 | 독립 테스트 세트 RMSEP로 전체 파장 PLS와 비교 | |

이론 선택성 계산에는 밴드 위치 ±15 cm⁻¹, 폭 ±15 %, 세기 ±20 %의 **모델 오차를 일부러 넣었습니다**.
실제 시료와 이론이 어긋나도 영역 선택이 버티는지 보기 위해서입니다.

## 실행

```bash
pip install -r requirements.txt
python run_experiment.py --repeats 5
```

결과: `results/report.md`, `results/*.png`, `results/results.json`

## 주요 결과 (시뮬레이션, 5회 반복)

- **400–1000 nm(가시광)는 당 정보가 거의 없음**: Morse 계산상 C-H/O-H 4~5차 오버톤은 1차 오버톤의 10⁻³ 이하.
  색소·산란 노이즈만 들어와서 400–2500 전체 PLS가 오히려 나쁨.
- **핵심 영역**: 약 1510–1610 (OH 1차 오버톤, 물 1450 nm 밴드 장파장 쪽), 1730–1810 (CH 1차 오버톤),
  2050–2210 (OH 결합대), 2270–2380 nm (CH 결합대). 전체의 약 22 % 파장만 써도 성능이 같거나 더 좋음.
- **삼당류 vs 사당류 개별 분리는 어려움**: 질량당 작용기 조성이 거의 같아서(라피노스와 스타키오스는 갈락토스 단위 1개 차이) NAS가 매우 작음.
  대신 **합(RFO)** 은 R² ≈ 0.93으로 잘 예측됨.
- **VIP 단독은 위험**: 가시광 색소 영역(400–680 nm)을 중요 변수로 잘못 고름.

## 한계

- 밴드 파라미터(ωe, ωexe, 결합 파트너 주파수)는 문헌 기반 근사값입니다. 실측 순수 성분 스펙트럼으로 보정하면 이론 영역의 정확도가 올라갑니다.
- 고체/분말 시료는 수용액보다 OH 밴드가 날카롭고 위치가 달라서, 삼·사당류 분리 가능성이 더 높을 수 있습니다.
- 최종 영역은 **반드시 실측 데이터의 독립 검증 세트**로 확인해야 합니다. 같은 데이터로 영역 선택과 평가를 모두 하면 성능이 과대평가됩니다.
