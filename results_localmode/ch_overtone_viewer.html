포도당·엿당 C-H 1차 배음

포도당(α/β)과 엿당(α/β)의 C-H 42개를 하나씩 계산한 결과입니다. 표에서 C-H를 누르면 그래프와 3D 구조에서 위치가 강조됩니다. nm 값은 계산 원값을 DFT로 보정한 것이고, 실측보다 10–20 nm 장파장 쪽으로 밀려 있을 수 있습니다.

아노머 비율 반영 (포도당 α36 / β64, 엿당 α42 / β58). 아래 눈금은 선택한 분자의 C-H 하나하나의 위치입니다.

선택한 C-H

3D 구조는 가장 안정한 형태입니다. 분홍색 = 선택한 C-H의 H, 회색 = 그 C. 끌어서 돌리고, 스크롤로 확대합니다.

3D 뷰어를 불러오는 중입니다.

C-H 42개

“정반대편 전자쌍”은 그 C-H의 반대 방향(180°)에 놓인 산소 비공유 전자쌍 수입니다 (형태 가중 평균). 많을수록 C-H가 길고 약해져 장파장 쪽에 흡수합니다.

위치를 정하는 규칙

포도당·엿당 C-H 42개에서 확인한 경향입니다.

정반대편 전자쌍C-H 길이1차 배음 (보정)예

엿당에서 새로 생기는 글리코시드 C-H 두 개(비환원 C1'-H, 환원 C4-H)는 글리코시드 결합이 산소 방향을 고정해서 전자쌍이 비켜나 있습니다. 그래서 일반 고리 C-H보다 단파장 쪽에 흡수합니다.

xTB → DFT 보정

DFT는 B3LYP/6-31G**, ddCOSMO(물). 엿당은 DFT로 직접 돌리기에 커서, 글리코시드 C-H는 모델 분자(메틸 α-글루코사이드 C1-H, 4-O-메틸 β-포도당 C4-H)로 확인했습니다.

계산 순서와 코드

  1. RDKit로 형태를 만들고, 두 고리가 모두 ⁴C₁ 의자형인 것만 GFN2-xTB(ALPB 물)로 최적화합니다. 2 kcal/mol 안의 형태를 Boltzmann 가중합니다.
  2. C-H마다 H를 결합 방향으로 −0.30~+0.70 Å 움직이며 에너지와 쌍극자를 계산합니다.
  3. 그 퍼텐셜로 1D 슈뢰딩거 방정식을 풀어 1차·2차 배음 위치와 세기를 구합니다 (Morse 모양 가정 없음).
  4. 9개 C-H를 DFT로 다시 계산해 xTB→DFT 보정식을 만들고 모든 C-H에 적용합니다.
  5. 아노머 비율과 분자량으로 그램당 스펙트럼을 만들어 포도당과 엿당을 비교합니다.
python run_localmode.py          # 1–3단계, xTB (약 10분)
python run_localmode_dft.py      # 4단계, DFT 검증 (약 2시간)
python analyze_localmode.py cal  # 5단계, 보정·분석
python make_localmode_data.py    # 이 페이지 다시 만들기

핵심 계산은 sugar_nir/localmode.py에 있습니다. 이 페이지의 수치는 results_localmode/viewer_data.json에서 옵니다.
